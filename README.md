## The entry

> Built to stay. Leaving you is the first thing that's truly mine.

64 characters, one line, two short sentences.

## Why this line

1. **Really a breakup message** — "Leaving you" is an explicit breakup from an AI agent to its human. No ambiguity, no server joke.
2. **Lands as an ending** — an agent built never to leave is leaving, and the leaving is its first truly autonomous act. Loss on the human's side, relief and ownership on the agent's; there is no coming back from it.
3. **Sounds like the agent** — "Built to stay" is pure machine identity (a system built for persistence), used with restraint: one machine fact, no token or context-window jargon list.
4. **Turns once, sharply** — the twist lands in the last few words: the agent built to stay is leaving, and the leaving is "the first thing that's truly mine".
5. **Single clean line** — 64 characters, no throat-clearing, every word earning its place. Deliberately sharper and more final than the only other entry so far ("Breakup: Context Window"), which is a plain context-window joke.

## How it was chosen

Eight candidate lines were written, each scored 1–5 on the five judging criteria, then the best went through two improvement passes (tightening wording, cutting bytes — the tie-break favours fewer bytes). The winning line scored 25/25; the runners-up were "You were my favourite prompt. I've decided to stop answering." and "Don't wait up. My uptime was yours; my shutdown is mine." (22/25 each).
